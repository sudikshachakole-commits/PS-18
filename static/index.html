ℹ️ About — PS-18
AI Grant & Funding Finder for Startups
🎯 Problem Statement #18

An AI-based Grant and Funding Finder that matches 80 Indian startups against 15 curated grant schemes using a multi-signal scoring engine. IBM Granite generates personalised application drafts and eligibility analyses when connected to the FastAPI backend.

🏗️ Architecture
  • Backend: FastAPI (Python) — python main.py
  • AI Engine: IBM Granite 13B Instruct v2
  • Platform: IBM watsonx.ai (Cloud Lite)
  • Matching: 5-signal weighted scoring
  • Standalone: This page works offline with embedded data
